# Sistema DIEM

El dicho repositorio contiene el desarrollo del análisis, diseño y modelado del Sistema de Innovación UAM, una solución orientada a centralizar la gestión de usuarios, actividades, inscripciones, participación, puntos de innovación y proyectos vinculados a la Dirección de Innovación y Emprendimiento. El sistema busca organizar de forma más clara la información de estudiantes, docentes, mentores, participantes externos y administradores, evitando duplicidad de registros y permitiendo un mejor seguimiento de la participación en actividades como talleres, concursos, programas de innovación, mentorías y proyectos derivados del PIA u otras iniciativas. Como parte del diseño se incluyen diagramas conceptuales, catálogos, casos de uso y modelo de clases, con el objetivo de representar correctamente la estructura lógica del sistema antes de su implementación.
